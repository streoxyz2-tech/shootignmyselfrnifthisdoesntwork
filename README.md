# Simple Noclip (Geode mod for GD 2.2081)

See the step-by-step guide in the chat, or:

1. Install Geode CLI + SDK (https://docs.geode-sdk.org/getting-started/geode-cli)
2. Edit `mod.json`: change `id` (e.g. `myname.simple-noclip`) and `developer`
3. Set `"geode"` in `mod.json` to your SDK version (`geode sdk version`)
4. `geode build`
5. Launch GD -> Geode -> Simple Noclip -> settings -> bind your key
