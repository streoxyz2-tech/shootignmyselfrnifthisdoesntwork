# Simple Noclip

Toggle noclip with a key you choose in the mod settings.

- **Bindable key** – set it in the mod's settings page.
- **Safe Mode** – when on, progress is not saved for any attempt where noclip was used.
- **NOCLIP label** – small, transparent label at the bottom of the screen while noclip is on. Opacity, size, colour, position and height are all adjustable.

Anti-cheat spikes still kill you, as in vanilla.
